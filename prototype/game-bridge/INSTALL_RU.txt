GAME BRIDGE 0.1.1 — УСТАНОВКА ИЗ CONNECTBOT

Это тестовая кнопка и чат перед подключением шашек. Автоответчика и API модели нет.
Архив запускает сервер. Подключение именно текущего чата GPT — следующий отдельный
этап; установка сама по себе не подключает GPT и не доказывает живой обмен.

1. Положить GameBridge_0.1.1.tar.gz в /root/ADOWNLOAD.
2. В ConnectBot под root выполнить:
   cd /root/ADOWNLOAD
   tar -xzf GameBridge_0.1.1.tar.gz
   bash GameBridge_0.1.1/install.sh

Повторное выполнение установщика не заменяет существующий /opt/game-bridge
и не перезапускает существующий одноимённый контейнер. При остановке сохранить
текст ошибки и передать GPT; вручную удалять каталоги не нужно.

Что требуется: Docker, curl, openssl, python3, ss, timeout, sha256sum;
интернет на VPS для Docker Hub/npm и минимум 900 MB свободного места на /opt
и Docker-разделе. Системные пакеты не устанавливаются автоматически.

Что создаётся:
- /opt/game-bridge — код, конфигурация и отдельные файлы данных;
- Docker image game-bridge-prototype:0.1.1;
- контейнер game-bridge-prototype, лимит памяти 192 MB, CPU 0.5;
- 127.0.0.1:3077 — приватный HTTP/MCP, не опубликован наружу;
- 0.0.0.0:3447 — HTTPS страница и MCP с раздельной авторизацией;
- /opt/game-bridge/data/events.sqlite — события и ответы;
- /opt/game-bridge/.env — секреты, не присылать в чат;
- /opt/game-bridge/player-url.txt — личная ссылка игрока;
- /opt/game-bridge/tls — самоподписанный сертификат, действителен 90 дней.

После надписи УСТАНОВЛЕНО открыть выведенную личную ссылку. Браузер предупредит
о самоподписанном сертификате. Подтверждать только адрес своего VPS
94.125.101.253:3447; отпечаток сертификата печатается установщиком.
Если политика браузера запрещает такой сертификат, потребуется доверенный
сертификат/домен; автоматический обход проверки не предусмотрен.
Серверное подтверждение нажатия должно появиться сразу. GPT пока не подключён.

Отдельный шаг подключения GPT:
Нужен доступ от инструментов активного чата к этому MCP. На VPS уже есть
Secure MCP Tunnel для других сервисов; их не менять и не использовать повторно.
Для Game Bridge требуется отдельный туннель/подключение, направленное на
http://127.0.0.1:3077/mcp с Authorization Bearer из AGENT_TOKEN.
Идентификатор нового туннеля и его настройки нельзя выдумать; они определяются
при создании подключения. AGENT_TOKEN игроку/публичной странице не выдаётся.
Установщик не создаёт аккаунты, туннели или плагин в ChatGPT.

Диагностика (без раскрытия секретов):
   docker ps -a --filter name=game-bridge-prototype
   docker logs --tail 40 game-bridge-prototype
   curl -fsS http://127.0.0.1:3077/health

Остановить только новый прототип:
   docker stop game-bridge-prototype
Запустить снова:
   docker start game-bridge-prototype
Данные и соседние службы при этих действиях сохраняются.

Существующие Cynteka, FoodTrack, GPT Notify, ГдеБЕНЗ, VPN, туннели и firewall
установщик не изменяет. Никаких docker prune/system prune.

Проверки до передачи: интеграционные тесты приложения и локальный HTTPS.
Реальная Docker-установка на вашем VPS и браузерная проверка ещё не выполнены.
