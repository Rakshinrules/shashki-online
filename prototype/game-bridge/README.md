# Game Bridge — проверка связи с текущим чатом

Прототип **до подключения шашек**. Кнопка и чат в браузере → собственный сервер →
MCP `wait_event` → ответ текущего ассистента через `reply` → та же страница.
OpenAI API, автоматического бота, PeerJS и публичного брокера здесь нет.

## Реальный статус

- Реализованы сервер событий, страница с чатом, постоянный журнал SQLite и MCP.
- Пять интеграционных тестов прошли локально 16.09.2026 на Node 24.19.0.
  Они используют официальный SDK как программный клиент, **не настоящую сессию GPT**.
- Размещение на VPS, подключение именно к этому чату, браузерная проверка и
  15-минутная живая сессия ещё НЕ выполнены. Время ответа GPT НЕ измерено.
- `.mcp.json` пока пуст: реальный адрес и способ подключения будут добавлены
  после размещения. Наличие манифеста не означает установленный плагин.
- Это одна личная тестовая комната. Управление несколькими комнатами и шашки
  намеренно не входят в этот проверочный этап.

## Запуск в изолированной среде

Нужен Node.js 24+. В каталоге проекта:

```sh
npm ci --ignore-scripts
npm test
node init-config.mjs
npm start
```

`init-config.mjs` создаёт локальный `.env` с двумя независимыми токенами и
не перезаписывает существующий файл. Секреты и SQLite не коммитить.
Страница: `http://127.0.0.1:3077/#token=<PLAYER_TOKEN из .env>`.
MCP: `http://127.0.0.1:3077/mcp`, заголовок `Authorization: Bearer <AGENT_TOKEN>`.
После чтения фрагмента страница удаляет токен из адресной строки и хранит его
в sessionStorage текущей вкладки. Токен ассистента браузеру не выдаётся.

На сервере нужны отдельный каталог, отдельный процесс/контейнер и проверенный
свободный порт. 3077 — только локальное значение по умолчанию, занятость на VPS
не проверена. Не менять соседние сервисы, VPN, GPT Notify или их туннели.
Не открывать эту страницу с токеном по незашифрованному внешнему HTTP.
Для внешнего доступа нужны HTTPS и PUBLIC_ORIGIN с точным origin страницы;
либо согласованный защищённый доступ. Dockerfile подготовлен, сборка на VPS не выполнялась.
При контейнерном запуске база должна лежать в постоянном volume `/data`.
Конкретный reverse proxy/порт выбрать только по актуальной карте и live-проверке.

## Подключение ассистента

Сервер использует официальный MCP SDK, stateless Streamable HTTP с JSON-ответами.
Его можно подключить как отдельный MCP сервер с Bearer-заголовком там, где клиент
это поддерживает. Доступность такой настройки в текущем ChatGPT ещё не проверена.
OAuth и Secure MCP Tunnel автоматически не настраиваются. Существующие туннели
пользователя не переиспользовать и не перенастраивать.

Также есть `agent.mjs`: транспортный клиент для инструментов текущего активного
чата. `GAME_BRIDGE_URL` и `AGENT_TOKEN` передаются через окружение; клиент
**не вызывает модель**, только читает события и отправляет написанный ответ.
Запуск `node agent.mjs wait_event`; для `reply` JSON `{id,replyTo,text}` через stdin.
URL должен быть доступен из среды выполнения ассистента — это ещё не проверено.

Во время партии ассистент остаётся в активном запуске, ждёт до 25 секунд,
получает событие немедленно при его появлении, отвечает и снова ждёт.
Окончание 25 секунд без события — нормальный пустой результат, не ошибка.
Завершённый запуск ChatGPT этот сервер самостоятельно не возобновляет.

## Доставка и проверка

Каждое сообщение имеет UUID; повторная отправка с тем же UUID не создаёт дубль.
В браузере неотправленные сообщения сохраняются в sessionStorage и повторяются
после восстановления сети. Неполученные ответы восстанавливаются из SQLite.
Ассистент получает все события без ответа, даже после переподключения клиента.
Повтор ответа с тем же UUID идемпотентен; второй иной ответ на то же событие отклоняется.

Браузер и MCP используют длинный HTTP-запрос ожидания: ответ отправляется при
появлении события, а не раз в 20–25 секунд. Это минимальный транспорт прототипа;
низкая задержка между разными сетями ещё требует измерения.

Перед подключением шашек проверить с настоящим пользователем:
1. Нажатие → событие у текущего GPT → собственный ответ GPT в чате страницы.
2. Несколько обменов без сообщений «сходил» в основном чате.
3. Отдельно время реакции страницы, серверного ACK и полного ответа GPT.
4. 15 минут, возврат фоновой вкладки, краткий обрыв сети, восстановление истории.

Источники: https://developers.openai.com/plugins/build/mcp-server
и официальный пакет `@modelcontextprotocol/sdk` (версия закреплена в package-lock.json).
